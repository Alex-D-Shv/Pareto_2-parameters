# Pareto_2-parameters
Данный репозиторий содержит исходный код программного комплекса для численного решения задач взаимодействия двух геометрических параметров постоянного магнита на величину магнитного поля и магнитного коэффициента через многокритериальную оптимизацию с построением фронта Парето.
